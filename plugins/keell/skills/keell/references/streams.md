# ストリームの仕様

出典：KEELL利用ガイド（https://doc.keell.jp/）。

## 作成中（下書き）と運用中

ストリームは作った直後は「作成中（下書き）」。運用中にすると公開され、タスクを進められるようになる（[ストリームを作成する](https://doc.keell.jp/2d06968af98c80618426f034d220bc1f)、[ストリームを運用中にする](https://doc.keell.jp/3f16968af98c80b9b3f4d6a38d97d374)）。

| | 作成中（下書き） | 運用中 |
|---|---|---|
| チームへの公開 | されない | される |
| タスクの完了 | できない | できる |
| 着手可能の通知 | 届かない | 届く |

- 運用中にできるのは、ストリームの管理権限を持つ人（オーナー・管理者・メンバー）
- **運用中にするには、すべてのタスクに担当者が必要**。空欄のタスクがあるとエラーになる
- 運用中にすると担当者に通知が届くため、その前にタスクの内容・担当者・期限日を確かめる
- 共有範囲：「プライベート」は担当メンバーだけが閲覧、「共有」は組織全体に公開

## タスクグループの「順番」と「同時」

（[タスクグループ内の順番/同時の切替](https://doc.keell.jp/34c6968af98c80d584c6fc5a026bce9a)）

- 順番：上から順に処理する。前のタスクが終わると、グループの一番上のタスクだけに着手可能の通知が届く
- 同時：並行して処理する。前のタスクが終わると、グループ内のすべてのタスクに通知が届く
- 切り替えると、テンプレートの所要日数、ストリームの開始日・期限日、ガントチャートの表示が変わる
- 切り替えられるのは、ストリームの管理権限・編集権限を持つ人

## 定期作成（繰り返し設定）

テンプレートからストリームを決まった周期で自動作成する機能（[ストリーム定期作成・繰り返し設定ガイド](https://doc.keell.jp/30b6968af98c80fe9d1dc3bb6763ed99)）。

- 「繰り返し設定」を作り、テンプレートに紐づける。1つの設定を複数のテンプレートで使い回せる。設定を変えると、紐づくすべてのテンプレートに効く
- 繰り返し設定の作成・編集・削除は、オーナー・管理者だけ
- 頻度：日（n日ごと）／週（n週ごと、第○週、曜日）／月（n月ごと、日付・第○週○曜日・第N営業日・最終営業日）。終了は「なし」「終了日」「実行回数」
- 営業日指定は、ワークスペースの営業日カレンダーで判定する。テンプレートで営業日カレンダーを使わない設定だと、営業日指定の繰り返しは実行されない
- 作られるストリームの期間は、定期作成が実行された日を開始日として計算される
- 作られるストリームは公開状態（下書きでは作られない）

**実行される条件（4つすべて）**

1. テンプレートが公開状態
2. テンプレートにストリーム管理者が1名以上いる
3. すべてのタスク（子タスクを含む）に担当者がいる
4. ストリーム作成者が、管理権限・編集権限・フォロワーに含まれていない（無人で実行されるため）

条件を満たさない日はスキップされ、実行履歴にも残らない。失敗した回は、設定 ＞ 繰り返し設定 の実行履歴から「手動で作成」できる。

## AIストリーム作成（β）

画像（フロー図など）かテキスト（「経費精算のフロー図を作って」など）から、AIがストリームのたたき台を作る機能（[AIストリーム作成（β）](https://doc.keell.jp/36c6968af98c80b09ac8f80db8863a64)）。

- ストリーム作成画面だけで使える（テンプレート作成画面では使えない）。ストリームが作成中（下書き）のときだけ
- 作られるタスクにはタイトルと期限だけが入る。説明・担当者は別途設定する
- β版のため、無料提供が予告なく終わる場合がある

## 通知

- 通知の受け取り先（KEELLの通知・メール・Slack）と種類（着手可能・コメント・アサイン・運用開始・デイリーレポート）は、各自が自分で設定する。ワークスペースごとに保存される（[通知の受け取り方を設定する](https://doc.keell.jp/4176968af98c81eeaf1df1379ca69f4c)）
- Slack連携は、KEELLの通知をSlackで受け取る一方向（[Slack連携](https://doc.keell.jp/3516968af98c8028a7d3fcc116144008)）
- 担当していないストリームやタスクの動きを追いたいときは「フォロワー」になる
