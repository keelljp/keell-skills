# Claudeにコネクタをつなぐ

KEELLのコネクタ（MCP）をClaudeに追加し、KEELLのアカウントでサインインします。Skillは、このコネクタを使ってKEELLを操作します。コネクタがないと、Skillを入れてもKEELLは操作できません。

詳しい手順と最新の画面は、KEELL利用ガイドの [ClaudeでKEELLを操作](https://doc.keell.jp/4216968af98c81a395aeed02d2d1bfa9) にあります。

## 使える条件

- KEELL：Standardプラン（トライアル中も使えます）のメンバー。無料プランのユーザーとゲストユーザーは使えません
- Claude：すべてのプラン

## Claude（Web・デスクトップ）

ClaudeにはKEELLの公式コネクタがあります。URLの入力は不要です。

1. 左メニューの「カスタマイズ」から「コネクタ」を開く
2. 「探索」で「KEELL」を検索し、KEELLのコネクタを追加する
3. 「連携」をクリックし、KEELLにサインインしてアクセスを許可する
4. 「自分のもの」の一覧から「KEELL」を開き、「ツールの権限」を設定する（下の「ツールの権限」）
5. チャットで「KEELLで今日のタスクを教えて」と頼み、KEELLの内容が返ってくることを確かめる

### Team・Enterpriseプランの場合

先に組織のオーナーが、組織にKEELLを追加します。追加しただけではメンバーはまだ使えず、各メンバーが自分の画面で「連携」します。

オーナーの設定がそろっていないと、メンバーが「常に許可」にしても毎回確認が出ます。オーナー向けの手順は [Claudeの組織にKEELLを追加する](https://doc.keell.jp/4216968af98c8168a503c5912d08eec6) を見てください。

## Claude Code

```bash
claude mcp add --transport http keell https://app.keell.jp/api/mcp
```

追加したあと、Claude Code で `/mcp` を開き、KEELLを選んでサインインします。

## ツールの権限

ツールごとに「常に許可」「承認が必要」「ブロック済み」を選べます。おすすめは次のとおりです（利用ガイドの [MCPでKEELLを操作](https://doc.keell.jp/4216968af98c81bbbc54d64168ef0260) と同じ分け方です）。

| 区分 | おすすめ | 例 |
|---|---|---|
| 読み取り | 常に許可 | 一覧、取得、検索、レポートの取得 |
| 作成・複製 | 常に許可 | タスクやストリームの作成（コメントの作成とユーザーの招待は除く） |
| テンプレートの組み立て | 常に許可 | テンプレートのカードの更新、まとめ、移動、並べ替え |
| 運用中の業務の変更 | 承認が必要 | タスクやストリームの更新、完了・スキップ・再開 |
| 公開・削除・復元 | 承認が必要 | 公開、アーカイブ、削除、復元 |
| コメント・ユーザー | 承認が必要 | コメント、招待、ユーザーやユーザーグループの変更 |

コメントはメンションした相手に通知が届くため、承認が必要にしておきます。テンプレートは運用中の業務ではないので、組み立ての操作を常に許可にしても実際の仕事には影響しません。

## 知っておくこと

- 操作は、サインインした本人として記録されます。コメントの作成者やタスクの完了者も本人になります
- 本人がKEELLの画面でできない操作は、Claudeからもできません
- 1つの接続で、本人が参加しているすべてのワークスペースを操作できます。複数のワークスペースがある場合、Skillはどれを使うかを確認してから操作します
- コネクタを削除して追加し直すと、ツールの権限は初期状態に戻ります。もう一度設定してください
